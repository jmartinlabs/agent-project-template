## Getting started
Follow the plugin's Quick start, the single place for all manual steps: https://github.com/jmartinlabs/agentic-harness-plugin#quick-start

1. Add the marketplace (required) with `claude plugin marketplace add jmartinlabs/agentic-harness-plugin#v1.0.0 --scope local`, then install the plugin as the Quick start says.
2. Trust the project: open it interactively once and accept the trust dialog.
3. Allow the plugin's files (Quick start step 4).
4. Run `/agentic:verify-project`.
5. Run `/agentic:init-project` (new project) or `/agentic:adopt-project` (existing code).
