## Getting started
1. Install the agentic harness plugin; see its Quick start: https://github.com/jmartinlabs/agentic-harness-plugin
2. Open this repository with Claude Code and trust the project when asked.
3. Run `/agentic:verify-project` to check the setup.
4. Run `/agentic:init-project` (new project) or `/agentic:adopt-project` (existing code).
5. Review and approve the generated `specs/` files.

Manual steps (plugin installation, permission rules) are documented in one place: the plugin's Quick start. Do not duplicate them here.
