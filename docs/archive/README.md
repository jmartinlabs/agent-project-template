# Archive

Historical records of how this template was built. They are **not methodology**:
agents should not load them to decide how to work, and derived or adopted projects
should not copy them.

| File | Content |
|---|---|
| `PROMPT_BACKUP.md` | original incomplete user prompt, verbatim |
| `PROMPT_BACKUP_COMPLETE.md` | complete user requirements, verbatim |
| `V2_4_2_AUDIT.md` | v2.4.2 integration audit |
| `V2_4_2_BENCHMARK.md` | v2.4.2 benchmark protocol (results UNRUN) |

Files were moved here with `git mv`; their content is unchanged except relative links.
Paths and decisions quoted inside them describe the state at the time they were written.
